# Marketplace portal (working name)

A B2B marketplace portal where suppliers and buyers sign up, manage their company profile and, in later milestones, connect with each other. It's a public showcase of my full-stack work in TypeScript, React, Node.js/Express and PostgreSQL.

**Status:** planning. No code yet. The first milestone is a walking skeleton deployed end to end.

## Why this exists

My professional work is Salesforce development, and I'm moving into general full-stack web development. I've been learning this stack in my own time, and this project is where that work becomes public. It rebuilds patterns I've built on Salesforce, from scratch, on a general web stack. Details in the project brief.
